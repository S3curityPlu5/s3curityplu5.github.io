# Mez Medici Media

This repository hosts the source code for **MezMediciMedia.com**, a creative media site featuring
original music, remixes, AI‑assisted artwork, and digital design projects by Mez Medici.

The site is deployed using **GitHub Pages** and automatically updates whenever new content
is added to the repository.
